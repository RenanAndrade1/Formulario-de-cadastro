# Formulario-de-cadastro 📋

## O projeto a seguir têm o objetivo de criar um formulário e um php para armazenar as informações coletadas.

## ✏️ O arquivo "Cadastro.html" contém a parte visual da página e do formulário, voltado para uma loja. Já o arquivo "Processacadastro.php" processa e armazena as informações recebidas.

## ⚠️ Para executar o projeto, é necessário ter um servidor-web em seu computador. Além disso, por enquanto não foi implementado banco de dados!

## 🤖 Como executar o projeto: Baixe os dois arquivos. Caso esteja usando o Xampp, coloque o projeto em uma pasta separa em htdocs dentro do servidor. Ative a opção APACHE da central de controle do Xampp e depois pesquise em seu navegador: localhost/nome da sua pasta/Cadastro.html
